Data Sources

Detailed data-source requirements are currently documented for ValueLens and StudioLens. Each lens's guide covers its sources, permissions, and setup requirements.

ValueLens

ValueLens uses one data model and one refresh. Its core (required) sources are Copilot interactions (Purview audit logs), licensed users (Microsoft 365 Admin Center), and org data (Microsoft Entra). Optional sources — such as Agents 365, credit and cost consumption, product feedback, and Copilot Studio transcripts — can be present or absent without ever breaking a refresh.

Open the ValueLens Data sources & requirements guide→

StudioLens

StudioLens requirements are path-scoped. The Dataverse (Direct) build reads Copilot Studio conversation transcripts live over the Dataverse Web API and needs an org-data CSV; the Fabric build reads Delta tables from a Lakehouse. Dataverse retains transcripts for about 30 days, so the Fabric build is the path for historical analysis beyond that window.

AI Insights

Sign in to use AI Insights

Use your organization's account with access to CopilotScope, its agent, and your Power BI data.

Access requirements

Your account

  • A work or school account authorized for this CopilotScope deployment and its published Copilot Studio agent.
  • Permission to view the report and Read + Build permission on its semantic model. Direct sharing or Viewer access with Build is sufficient; an administrator or editor role is not required. Row-level security still applies.
  • For shared Power BI content: Pro (or PPU), unless eligible Premium capacity or Fabric F64+ allows Free users to consume it. Shared content on F2–F32 still requires Pro or PPU. PPU workspaces require PPU. Personal My Workspace use follows separate Free-user rules.
  • No Copilot Studio maker license or Microsoft 365 Copilot add-on is required just to use this published website agent. Power BI requirements still apply.

Your organization

  • A published agent with Copilot Studio capacity or pay-as-you-go enabled for website use. A maker trial or Teams-only entitlement is not sufficient for this website deployment.
  • For the current Power BI query-generation route: eligible paid Fabric F2+ or Premium P1+ capacity, or a configured Fabric Copilot capacity, with Copilot enabled in a supported region. Pro or PPU alone and trial capacity do not provide this capability.
  • The Power BI MCP preview endpoint enabled for the user, approved delegated application permissions for Power BI and Copilot Studio, and applicable agent sharing/security-group membership.

We check application access, report/model queries and the delegated Studio token without generating an answer. Licenses, agent access and service capacity remain subject to checks when a request runs.
